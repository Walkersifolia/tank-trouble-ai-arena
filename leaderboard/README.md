# 排行榜

`local.js` 收拢网页现有 AI 对战榜单的累计与表格渲染。比赛结果和死亡事件来自共享 `engine/`；此模块不实现另一套比赛物理或 AI 调度。

当前榜单仅统计本浏览器完成的 AI 对战，记录局数、胜负平、击杀、自杀、决策超时与胜率，并保留原有胜场／胜率排序。网页仍使用原来的 `tank-trouble-web-challenge-v1` localStorage 键及 `aiStats` 字段，因此同一网站来源下的既有记录继续可用。真人挑战战绩独立保存在网页中。

这里只包含已有的浏览器本地榜单，尚无服务器排行榜、官方统一排名或上传成绩功能。后续排行榜代码集中放在本目录，并复用共享引擎及 `devtools/matches/` 的对战能力。
