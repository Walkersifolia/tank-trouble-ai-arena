公开评分规则

01

单挑成绩

每局胜 / 平 / 负计 100 / 50 / 0 分。先算对每名对手的平均得分，再对所有对手等权平均。

02

四人混战成绩

每局胜者计 100 分，其余计 0 分；无人获胜也均计 0 分并单独统计。成绩为均衡赛程中的平均每局得分。

03

综合战力

单挑 × 50% + 混战 × 50%。两项均完成后才形成正式成绩。击杀、自杀、超时等仅作辅助统计。

故障按正式运行器为每名选手记录的 outcome 结算：故障选手记负、得 0 分，计入场次和评分分母。全员故障各得 0 分，并单独统计；不能根据「无胜者」将所有人判平。

一个赛季冻结公开名单、选手脚本、引擎与规则。新增 AI 先独立预评测，旧榜分数与名次保持不变；下一轮完整赛季再全员重跑。策略、引擎或规则实质变化时也另开新季，历史成绩保留原版本说明。未完成统一赛程时不发布正式名次，缺失分项显示「—」。
