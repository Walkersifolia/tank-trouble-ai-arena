# 网页竞技场

[打开游戏](https://walkersifolia.github.io/tank-trouble-ai-arena/)。Web 是唯一游戏版本，页面与物理在访客浏览器运行。

## 开始对战

1. 默认从新手对手“哨兵”开始，也可选择其他网站 AI，或者点“导入 AI”选择本机 `.js` / `.cjs` 文件。
2. 选择“真人 VS AI”，设置自己的名字、颜色和比赛规则，确认参赛席位后进入战场。
3. 选择“AI VS AI”可让多个 AI 自由混战；真人模式最多一名真人，也可同时启用多个 AI。网站选手从阵容的固定下拉列表添加，名称固定；仅本地导入的 JS 选手可以编辑名字。颜色、启用状态和控制者可以调整。
4. 结束后可再次挑战或更换对手。默认随机迷宫、60 秒时限；玩法可选“有道具对战”（默认）或“纯走位开火 · 无道具”，两种玩法均不破坏墙体。无道具玩法仅有普通反弹炮弹，不生成散射、激光、地雷或护盾道具。

有真人参与的对局，AI 不因单次决策超过 50 ms 判负；纯 AI 对局仍执行 50 ms 决策预算。两种模式均保留原有脚本无响应时的 250 ms 硬终止与故障处理。

双人地图为 9×7 格；更多选手沿用原按人数增长的尺寸，以 9×7 为最小场地。每格仍为 96 个逻辑像素，含履带车身为 51×48，约占半格；外观、运动接触、命中半径及炮口同步放大。地图、坦克和子弹共用同一个等比显示缩放，小地图整体放大、大地图整体缩小，移动和弹速数值不变。格栅与对称风格的初始放墙概率提高到 40%，之后仍保留既有连通处理；房间风格减少额外开门。新比赛使用新尺寸与地形分布，旧赛季成绩应保留对应的引擎版本。

结束弹窗现在提供“换图再来”“同种子重赛”“回放与诊断”“下载录像”。同种子重赛保留阵容、规则、地图、出生及独立随机流；每位 AI 的 `Math.random` 从同一席位种子重新开始。仍使用实际时钟，纯 AI 对局执行正式 50 ms 决策预算，因此真人操作、按时间限额搜索和超时判负可能改变结果；道具落点也会受当局占位/拾取影响，不保证重赛全过程相同。

回放读取当局已记录的60Hz状态，不重新运行AI或物理。可播放、暂停、逐Tick前后、拖动时间轴、调倍速和选择坦克；诊断并列显示连续指令、真实位移/转角、实际速度、接触及最近1秒反向次数。接触与低位移同时发生并不能单独证明碰撞故障，回放也不记录屏幕刷新停顿。下载的JSON不含AI源码；刷新后可从大厅“打开录像”重新查看。详细状态沿用现有64MiB估算上限，达到上限会提示可回放截止时间，全局摘要仍记录整局。

电脑版使用以下操作，移动、转向与射击可以同时进行：

当前共享运动核心按原版前后速度比例设置：前进 153.12 px/s、倒车 122.88 px/s，原地转向 5 rad/s；没有驾驶惯性，松开移动键即可停止主动平移，也可边走边转。车身、履带外轮廓及炮管会与有厚度的墙面接触，贴墙与拐角会影响实际转向。画面在真实物理姿态之间插值，AI 观测仍取真实位置；显示平滑不会延迟输入或强制保持动作。

| 操作 | 按键 |
| --- | --- |
| 前进 / 倒车 | W / S，或 ↑ / ↓ |
| 左转 / 右转，包括原地转向 | A / D，或 ← / → |
| 持续开火 | 按住 Space |
| 特殊操作 / 布雷 | Shift |
| 暂停 | Esc，或画面上的暂停按钮 |

手机横竖屏均可游玩，推荐横屏。竖屏时画面在上、触控区在下，横屏建议提示约 4 秒后自动消失，不拦截操作。左摇杆的**纵轴控制前进、倒车，横轴控制转向**，不会自动朝某个方向行驶；左右拖动可原地旋转，斜向拖动可倒车同时转向。右侧大按钮可持续按住开火，小按钮使用特殊操作。支持左手摇杆与右手开火同时触摸；松手、触控中断或切到后台会清除持续输入。发射频率由原有武器规则决定。

点击“全屏”仅请求全屏，不锁定屏幕方向。手机通常自动显示触控区，也可在设置中打开“显示触控”。

## AI 连续对战

AI 模式支持场次、速度和不绘制画面的尽速比赛；使用同一正式引擎与 50 ms 决策预算。排行榜保存在当前浏览器，包含胜负平、主动击杀、自杀和决策超时。最近结果可回看，本地导入脚本仍只存于页面内存。具体比赛记录以实际完成局为准，中途停止不计为正常结果。

## 开发脚本

`module.exports = { update(state) { return { move: 1, turn: 0, fire: true, special: false }; } };`

脚本必须同步、自包含，仅使用公开观测，不依赖 Node.js、DOM、网络或外部模块。每局重新初始化，每个席位独立运行。`move/turn` 为 [-1,1]，`fire/special` 为布尔值。完整接口见 [开发包 API](../devtools/training/starter-kit/API.md)。

预设直接维护在`bots/roster.json` 和 `bots/`；新增公开选手须有明确发布授权。网页脚本对所有访客可见。神谕和本机私有对手不加入公开清单。

## 唯一发布流程

维护工作区：`D:\Documents\ChatGPT\坦克动荡AI斗蛐蛐\tank-trouble`。中文目录是唯一发布源。

1. 修改根目录 HTML、预设、`bots/`、`web/` 或共享源码。
2. 只有开发包资料改变时执行 `npm run kit:package`，提交对应 ZIP。
3. 提交并推送 `main`，由现有 GitHub Pages **main / 根目录** 的 `pages-build-deployment` 自动构建发布。

保留 `.nojekyll`，无需本地构建、`dist` 同步或本地 Web 测试包装脚本。现有 `build.mjs`、`serve.mjs` 和对应 npm 命令已移除。训练包使用 `npm run training:package` 生成后上传 Releases，网页的固定下载链接不随版本改变。

无界面评测和关键日志见 [PROTEUS 研究目录](../devtools/research/proteus/README.md)。Windows 黑盒训练服务及打包命令保留，见 [训练说明](../devtools/training/README.md)。旧桌面的日志与录像保留在 `local-data/`，不上传。
